# PROF_2027 — план разработки

Каждый этап заканчивается результатом, проверкой и **коммитом** — можно откатиться.

| Этап | Результат | Проверка |
|---|---|---|
| **0. Каркас** | структура, конфиг, `.env.example`, БД (8 таблиц), YAML-каталоги, CLI, пользователи, тесты | `init`, `--help`, тесты проходят |
| **1. Загрузчик (А)** | фильтр файлов, парсинг, OCR, классификация, аннотация, модерация, отчёт | 10 файлов обработаны, дублей нет, `.exe→.pdf` в карантине |
| **2. Датасет (А)** | признаки, prev/next, важность, описание, графики | все поля на месте, графики строятся |
| **3. Кластеризация (Б)** | 3 стратегии, метрики, t-SNE | метки и метрики сохраняются |
| **4. Обучение (В)** | 3 задачи × ≥3 алгоритма, дрейф, версии | ROC-AUC, GroupKFold, утечки нет |
| **5. Прогноз (В)** | время, траектории, Gantt | дедлайн и часы/день учитываются |
| **6. Дашборд (Б)** | Dash, роли, 10 вкладок | все вкладки работают, роли ограничивают |
| **7. API (Г)** | FastAPI, Swagger, API-ключ | все эндпоинты КЗ покрыты |
| **8. Бот (Г)** | aiogram polling, команды, файлы | отвечает на всё, пустой токен не роняет |
| **9. Отчёты (А–Д)** | отчёты и документация | развёртывание по документации |
| **10. Сборка (Д)** | PyInstaller, офлайн-проверка, демо ≤10 мин | одна команда на агента, без интернета |

Сроки: этапы 0–2 ~ неделя, 3–5 ~ неделя, 6–8 ~ неделя, 9–10 ~ неделя. Итого ~25–35 дней, зависит от данных.

Порядок приёмки: демонстрация → чек-лист КЗ → правки → коммит → следующий этап.
