# PROF_2027 — какие данные нужны

Приоритеты: **P0** — без этого нельзя начать, **P1** — до финальной сборки, **P2** — улучшения.

## P0

### 1. Файлы материалов (10–20 шт.)
PDF, DOCX, PPTX, HTML, TXT, изображения, 2–3 коротких видео. Белый список:

| Группа | Расширения |
|---|---|
| Документы | `.pdf`, `.docx`, `.doc`, `.pptx`, `.ppt`, `.rtf`, `.txt`, `.md` |
| Веб | `.html`, `.htm` |
| Изображения | `.png`, `.jpg`, `.jpeg`, `.webp`, `.bmp`, `.tiff` |
| Видео | `.mp4`, `.mov`, `.avi`, `.mkv` |

Лимиты: 100 МБ на файл, 500 МБ на видео, 2 ГБ за запуск. `.zip` не распаковывается. Переименованный `.exe` уходит в карантин.

### 2. Подтверждение каталога предметов
`config/subjects.yaml` — 9 категорий, ~30 дисциплин. Подтвердить или дополнить.

### 3. Подтверждение методических требований
8 категорий × 3 требования (24) из `sava`. Можно просто подтвердить или дать свои — заменяется одним YAML.

### 4. Золотой набор — 30 материалов
С эталонными: категория, дисциплина, тема, уровень образования, сложность (1–5), вердикт модерации. Формат XLSX/CSV/YAML.

### 5. Пары «параллельно / последовательно» — 20–50 шт.
```yaml
- material_a: 3
  material_b: 15
  relation: parallel   # разные предметы
- material_a: 3
  material_b: 7
  relation: sequential # внутри предмета, продолжение
```

### 6. Нормы времени — хотя бы по 10 материалам
```csv
material_id,minutes
1,25
2,40
```

### 7. Железо
ОС, CPU/GPU, RAM, свободное место, будет ли интернет на демо, допустимо ли ~4,6 ГБ моделей.


## Демо-набор (текущий)

Для офлайн-демонстрации используется синтетический набор: `scripts/make_smoke_pdf.py`
генерирует 3 учебных PDF (дроби, кинематика, химическая связь), загрузчик обрабатывает их
реальными моделями в `data/demo.db`. Боевые данные из раздела P0 нужны для полноценного
обучения моделей (3 задач) и убедительной демонстрации.
